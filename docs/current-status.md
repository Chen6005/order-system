# 目前 MVP 狀態

## 目前已完成的功能

- 顧客可以在首頁瀏覽今日菜單。
- 顧客可以將餐點加入購物車。
- 購物車會顯示商品數量、小計與總金額。
- 顧客可以調整購物車內商品數量。
- 顧客可以送出訂單。
- 送出訂單後會顯示成功訊息並清空購物車。
- 管理端區塊可以查看目前送出的訂單。
- 管理端可以更新訂單狀態。
- 使用者介面已改為繁體中文。

## 目前資料狀態

目前購物車與訂單資料仍只存在 local React state。

這表示：

- 重新整理頁面後，購物車與訂單資料會消失。
- 不同瀏覽器或不同裝置之間不會共享資料。
- production 上的資料尚未寫入資料庫。
